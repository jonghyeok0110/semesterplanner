# 학기 플래너

대학 생활용 일정 웹앱이에요. 월간·주간(시간표)·일간 보기, 과목별 색 구분, 과제 D-day, 구글 드라이브 동기화를 지원해요.

## 파일 구성

모든 파일을 저장소 맨 위(루트)에 폴더 없이 올리면 돼요.

```
index.html             앱 본체
manifest.webmanifest   홈 화면 설치용 설정
sw.js                  오프라인 실행용
logo.svg, logo-1024.png, logo-fullbleed.svg    로고
favicon.svg, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png    앱 아이콘
```

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들어요. 예: `semester-planner`
2. 압축을 푼 파일 전부를 저장소 맨 위(루트)에 올려요.
3. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`로, Branch를 `main` / `/ (root)`로 고르고 저장해요.
4. 1~2분 뒤 `https://아이디.github.io/semester-planner/` 링크가 생겨요.

폰에서 링크를 연 뒤 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 2. 구글 드라이브 동기화 설정 (선택)

설정하지 않아도 앱은 동작해요. 이 경우 데이터는 그 기기의 브라우저에만 저장돼요.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만들어요.
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 찾아 **사용**을 눌러요.
3. **OAuth 동의 화면**을 설정해요.
   - 사용자 유형은 **외부**로 골라요.
   - 앱 이름(예: 학기 플래너)과 이메일을 입력해요.
   - 범위에는 `.../auth/drive.file` 하나만 추가해요.
   - 게시 상태는 **테스트**로 두고, **테스트 사용자**에 본인 Gmail을 추가해요.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**로 가요.
   - 유형은 **웹 애플리케이션**으로 골라요.
   - **승인된 JavaScript 원본**에 `https://아이디.github.io`를 넣어요. 저장소 이름은 빼고 넣어요.
   - 만들어진 `…apps.googleusercontent.com` 값을 복사해요.
5. 앱의 **과목 탭 → 백업·구글 드라이브 동기화**에 클라이언트 ID를 붙여넣고 **저장하고 연결**을 눌러요.
   - 매번 입력하기 싫으면 `index.html`의 `const GOOGLE_CLIENT_ID='';`에 직접 넣어도 돼요. 클라이언트 ID는 공개돼도 괜찮은 값이에요.
6. 다른 기기에서도 같은 링크를 열고, 같은 구글 계정으로 연결해요.

### 알아둘 점
- 앱은 자기가 만든 파일만 볼 수 있어요. 드라이브 맨 위에 `semester-planner.json`(본 데이터)과 `semester-planner-backup-날짜.json`(복원 지점, 최근 10개)을 만들어요.
- 테스트 모드에서는 처음 연결할 때 "Google에서 확인하지 않은 앱" 경고가 떠요. 본인이 만든 앱이니 **계속**을 누르면 돼요.
- 로그인 토큰은 1시간쯤 지나면 만료돼요. 그러면 위쪽 구름 아이콘이 **+** 모양으로 바뀌어요. 눌러서 다시 연결하면 돼요. 그사이 고친 내용은 이 기기에 저장돼 있다가, 다시 연결하면 올라가요.
- 두 기기에서 연결이 끊긴 채로 각각 고치면 나중에 고친 쪽만 남아요. 이럴 땐 복원 지점이나 백업 파일로 되돌리세요.
- 홈 화면에 설치한 앱에서 구글 로그인 창이 안 뜨면, 브라우저에서 링크를 직접 열어 연결해 보세요.

## 3. 수정한 뒤 다시 올릴 때
